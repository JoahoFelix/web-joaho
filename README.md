#PROYECTO WEB-JOAHO 
## Estructura del proyecto 
- css : contiene los estilos de la pagina
- imagenes : contiene la imagen para la pagina
- js : archivos Javascript
- test: contiene las pruebas que se realizan **pero no se publicaran

## Tecnologiaas a utilizar
- HTML
- CSS
- Javascript

## Informacion sobre la tarea
- Se construira una pagina web de tema libre, esta permitido la generación de CSS utilizando herramientas basadas en IA.
- La web debera ser construida utilizando HTML semántico y debera considerar: imágenes, tablas, enlases, formularios y con contacto para redes sociales.
- Todo el contenido debe estar dentro del archivo index.html.
- Crear un archivo de estilos y guardarlo en la carpeta CSS, lo mismo crear un archivo de funciones y almacenar en la carpeta JS.
